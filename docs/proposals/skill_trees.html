Skill Trees

A proposal for card #136 and the three hero reworks (#56 Alder, #80 Brin, #81 Cass). Nothing here is built yet. Pick the two answers in the gold box, change anything you like, and I will build from it.

Two choices for you

  1. How many skills does a hero bring into a fight? 5, like today (my pick: the action menu stays short and a choice still matters), or 6, like Expedition 33.
  2. How are skill points earned? 1 per level (my pick: a full run reaches about level 6, so you finish a branch or two, never the whole tree), or 2 per level (you see most of the tree each run).

How it works

  • Each hero has 9 skills in 3 branches. They start a run with the 3 skills at the top of each branch.
  • A level up gives a skill point (on top of the 3 attribute points). The second skill of a branch costs 1 point, the third costs 2, and each needs the one above it. So a whole tree costs 9 points.
  • Before a fight you choose which unlocked skills to bring, up to the slot limit. This happens on a new "Skills" page next to the attributes page (party screen).
  • Everything resets each run, as decided for #139.
  • All numbers below are first guesses. They go in the skill data files, so we tune them after you play.

What has to be built

New fight rules: Bleeding (damage at the start of a turn), Renew (healing at the start of a turn), Marked (a bonus for the next 3 skills), a party-wide guard, a heal for the whole party, and "every enemy must attack Alder". New art: Alder's shield-only poses (his sprite already lost the sword), Brin's dual-dagger poses and two-hit attack, Cass's staff and spell bolts. Then the Skills page, skill points on level up, and the bot learning to pick skills.

Revive moves deeper into Cass's tree, so early in a run only the Team Ultimate can revive. If that feels too harsh, Revive can be a starter instead of Reveal.

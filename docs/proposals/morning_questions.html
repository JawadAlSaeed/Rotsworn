4. The tutorial

Six short lessons on the practice fight. Each shows one line of text, waits until you do it, and can be skipped with Start.

  1. Attack. Press when the ring closes. Done after one good press.
  2. Skills. Cass uses Reveal, Brin uses Rend on the Exposed enemy, the others press for follow-ups.
  3. Defend. A slow single hit: parry it. Then dodge one. Then jump a ground wave. The training ring is on for this lesson.
  4. Counter. Parry every hit of a short string to strike back.
  5. Team Ultimate. The gauge starts full: use it.
  6. Zone and map. Walk, hit a roaming enemy first for FIRST STRIKE, pick up a glint, then choose a path on the map.

When does it show? Offered once, the first time you start a run, and always in the main menu, or only in the main menu.
